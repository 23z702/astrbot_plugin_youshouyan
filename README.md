# 有兽焉追番（astrbot_plugin_youshouyan）

AstrBot 插件：发送 `/看 有兽焉第12话`，从站点媒体接口取回临时播放直链并以视频消息发到群里。

数据来源：`/api/media.php`（`list` 检索 + `video` 换取限时直链），鉴权用 `X-API-Key`。

## 支持的说法

| 输入 | 结果 |
| --- | --- |
| `/看 有兽焉第12话` | 第 12 话 |
| `/看 有兽焉 第12集` | 第 12 话 |
| `/看 有兽焉 12` | 第 12 话 |
| `/看 有兽焉第十二话` | 第 12 话 |
| `/看 有兽焉第1-3话` | 第 1、2、3 话（上限 `max_range`） |
| `/看 斗破苍穹第5话` | 换成别的片子也能搜，片名跟着指令走 |
| `/看 第12话` | 片名省略时用配置里的默认关键词 |
| `/找 有兽焉` | 列出匹配到的文件（不带话数就是搜索） |

指令别名：`看有兽焉`、`youshouyan`、`kan`；搜索指令 `/找`（别名 `搜索` / `搜` / `search` / `find`）；另有 `/有兽焉帮助` 和 `/有兽焉自检`（调用 `action=info` 显示密钥名、作用域、有效期、调用次数，排障先跑这个）。
闲聊里顺口带「看」字（例如「看这个」）不会触发；`/看 关键词` 只有以 `/` 开头时才当搜索，避免误触。

### 搜别的文件

- 关键词不再写死成「有兽焉」：指令里写了片名就以它检索，没写才用配置里的 `keyword`。
- `/找 关键词` 列出匹配的文件（文件名或所在目录名包含关键词即命中），
  只命中 1 个时直接播放，命中多了列前 `search_limit` 条并提示缩小范围。
- 公共网盘按**目录名 + 文件名**匹配，所以「有兽焉」目录下的「第1话 貔貅驾到.mp4」也搜得到。

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/23z702/astrbot_plugin_youshouyan.git
```

也可以下载压缩包解压到 `AstrBot/data/plugins/astrbot_plugin_youshouyan/`——目录名必须是 `astrbot_plugin_youshouyan`，带连字符 AstrBot 加载不了。

重载插件后在管理面板启用，再填下面的配置。

## 必填配置

| 配置 | 说明 |
| --- | --- |
| `api_base_url` | `https://你的域名/api/media.php`（中文域名会自动转 punycode，填中文或 `xn--` 形式都行） |
| `api_key` | `pk_` 开头 51 字符，用户中心 → 视频 API → 新建密钥（明文只显示一次） |

密钥用 `X-API-Key` 请求头发送，不依赖 nginx 透传 `Authorization`。
若站点只认 `Authorization: Bearer`，把 `api_key_header` 改成 `Authorization`、`api_key_prefix` 改成 `Bearer `（含空格）。

⚠️ 密钥等于「以你的身份读文件」：只填在 AstrBot 配置里，不要进前端、公开仓库或截图。

## 视频来源

两个来源用的不是同一个接口，插件会自动分辨：

| `source` | 走哪个接口 | 说明 |
| --- | --- | --- |
| `public`（默认） | `/api/public.php` | 公共网盘。接口会从根目录开始遍历目录树，带密码的目录用配置的密码进入 |
| `own` | `/api/media.php` | 只读自己的网盘，`action=list` + `action=video` 换临时直链 |

**为什么公共网盘不用 `media.php`**：`media.php?source=public` 只列公开部分，受密码保护的目录**完全不返回**，带不带密码都一样。而公共网盘的内容往往全在带密码的目录里，所以插件改走站点前端用的 `public.php`：先列根目录，再用密码逐层进入子目录，取到文件后拼出播放地址。

**受密码保护的目录**：`folder_password` 填目录密码即可，一行一个（也支持逗号、竖线分隔），插件会依次试，能打开哪个就用哪个，并记住每个文件对应哪条密码。公共网盘的播放地址优先用列表返回的签名（`exp` + `sig`，默认约 2 小时），签名过期或缺失时才退回「带目录密码」的地址——两者都支持 HTTP Range，能拖进度条。

`/有兽焉自检` 会分别列出「我的网盘」和「公共网盘」的视频数，并标出当前用的是哪个——内容在哪边一眼就能看出来。

它还会顺便读一次公共网盘的目录结构（`api/public.php?action=list&folder_id=0`，不需密钥），带 🔒 的目录就是设了密码的。如果公共网盘显示 0 个视频、而目录列表里有 🔒，那就是密码没填或填错了。

### 检测失败 / 0 个视频时怎么办

自检的两个网盘数是**实时查**的，接口偶发超时会重试一次（`count_videos` 和目录列举各重试一次，密钥类/限流类错误不重试，免得越试越糟）。如果结果还是 0 或者显示「查询失败」，自检会直接给出网盘站点地址，告诉用户去站点注册/登录、上传文件、在「用户中心 → 视频 API」创建密钥。

站点地址用 `site_url` 配置，留空则用代码里的默认站点。同样的提示也会出现在这些地方：

- `/看`、`/找` 找不到文件时（附加「浏览器打开站点上传」的指引）；
- 401/403（密钥失效或作用域不足）时，提示去站点重新创建密钥；
- 插件还没配置好时。

另外，公共网盘扫描到 0 个文件时**不写缓存**，所以接口恢复后再发一次自检/指令就能立刻看到内容，不会被一次失败的结果粘住 `cache_ttl` 秒。

## 工作流程

```
/看 有兽焉第12话（source=public）
  ├─ GET /api/public.php?action=list&folder_id=0          ← 根目录，拿子目录
  ├─ GET /api/public.php?action=list&folder_id=1&folder_password=xxx
  │     ← 密码错会返回 code 2，换下一个密码再试；结果缓存 cache_ttl 秒
  ├─ 用文件名匹配第 12 话，多个命中取最像的、再取上传时间最新的
  └─ 拼播放地址 /api/public.php?action=preview&id=43&exp=..&sig=..
        ← 支持 Range，可直接丢给播放器

/看 有兽焉第12话（source=own）
  ├─ GET /api/media.php?action=list&q=有兽焉&page=1&page_size=100
  └─ GET /api/media.php?action=video&id=123&ttl=7200
        └─ 发视频消息（超过 max_send_size_mb 则改为发直链文本）
```

### 文件名匹配规则

| 文件名 | 识别为 | 说明 |
| --- | --- | --- |
| `有兽焉 第12话 1080p.mp4` | 第 12 话 | 「第N话/集/期」最可信 |
| `有兽焉.S01E05.mkv` | 第 5 话 | `E05`/`EP05` 次之，季号 `S01` 会被剔除 |
| `有兽焉 [12].mp4` | 第 12 话 | 括号数字 |
| `有兽焉 1080p 第2话.mp4` | 第 2 话 | 分辨率/编码等噪声先剔除，不会被当成话数 |
| `有兽焉 第12话 预告.mp4` | 第 12 话 | 但会扣分，同一话有正片时优先正片 |
| `有兽焉 主题曲.mp3` | 不匹配 | 非 video/ 的 mime 直接过滤 |

同一话命中多个文件时，取匹配可信度最高的；同分再取 `create_time` 最新的。

### 发送策略（三级降级）

1. **视频消息**：文件 ≤ `max_send_size_mb`（默认 50MB）时直接发，群里点开即播；
2. **群文件**：视频消息发不出去（或文件太大）时，先把视频拉到本地临时目录，
   再用 OneBot 的 `upload_group_file` 传到群文件 —— 上限大得多，几百 MB 也 OK；
3. **直链**：以上都失败才发文本直链。

为什么要卡 50MB：QQ 群视频走 highway 上传，实测 77MB 的文件会在传到 ~52MB 时被拒
（`retcode=1200 / HTTP Upload failed with code 102902`），此时插件只会在日志里留一条 ERRO，
用户那边什么都收不到。现在插件自己 `await event.send()` 捕获这个异常，并顺手：

- 把本次学到的体积上限记下来（失败体积 × 0.6，最低 10MB），
  之后更大的文件跳过第 1 步，**不再每次都白等一次几十秒的上传**；
- `/有兽焉自检` 会显示当前的「直发上限」和「发送方式」。

小文件不受影响：只有真正上传失败才会收紧上限，未失败过就按 `max_send_size_mb` 走。

群文件的几个前提：必须是**群聊**（私聊没有群文件）、协议端要实现 `upload_group_file`
（NapCat / LLOneBot 都支持，不支持时会自动退回发直链）、群容量要够。
临时文件下载到系统 temp 目录，传完即删。

`upload_mode` 可以固定行为：`auto`（默认，三级降级）/ `video`（只发视频消息）/
`group_file`（一律传群文件）/ `link`（只发直链）。

## 其余配置

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `source` | public | 视频来源：`public` 公共网盘 / `own` 自己的网盘 |
| `site_url` | 代码内默认站点 | 回复里提示用户去注册/上传的站点地址，留空用默认 |
| `keyword` | 有兽焉 | 默认片名，指令里没写片名时用它 |
| `search_limit` | 10 | `/找` 一次最多列多少个文件 |
| `folder_password` | 空 | 受密码保护的公共目录密码，多个用换行/逗号分隔 |
| `play_ttl` | 7200 | 直链有效期（接口允许 60~86400） |
| `cache_ttl` | 300 | 文件列表缓存；查不到话数时会自动强制刷新一次 |
| `page_size` / `max_pages` | 100 / 5 | 最多检索 500 个文件 |
| `max_episode` | 0 | 话数上限，0 不限；填了就本地拦截，不浪费请求 |
| `max_range` | 3 | 一次最多查几话 |
| `max_send_size_mb` | 50 | 超过就不发视频消息（改走群文件/直链）；0 = 不限制（不建议） |
| `upload_mode` | auto | `auto` / `video` / `group_file` / `link` |
| `download_timeout` | 180 | 传群文件前从网盘下载的超时（秒） |
| `link_only` | false | 一律只发直链，不尝试上传 |
| `timeout` | 15 | 单次请求超时 |
| `extra_headers` | `{}` | 附加请求头（如 Referer） |

## 错误提示

接口错误码会翻成中文，401/403/429/503 额外给出处理建议：

| code | 提示 |
| --- | --- |
| 401 | 密钥无效/已撤销/已过期 → 去站点重新创建，回复里带站点地址 |
| 403 | 作用域不足（缺 `media`）→ 去站点重新创建 |
| 404 | 该话文件不存在（或不属于这个账号）；顺带提示锁着的目录、以及去站点上传 |
| 415 | 文件不是可播放视频 |
| 429 | 触发限流（按 IP，15 分钟 30 次） |
| 503 | 服务端没跑 `install/migrate.php` |

### 公共网盘提示「请先登录」

站点把公共网盘设成**只对登录用户开放**（页面里的 `PUBLIC_GUEST = false`）时，`api/public.php` 连根目录、连签名预览地址都会返回 `code 401 请先登录`。这种情况下插件、QQ 播放器都拿不到内容，不是密钥的问题。两种解法：

1. 站点后台打开「公共网盘允许游客访问」（`PUBLIC_GUEST = true`），插件立即可用；
2. 把文件放到自己账号的网盘，配置里 `source` 改成 `own`，走 `api/media.php`（需要该账号的 API 密钥，作用域 `media`）。

插件遇到这个 401 时会直接说明原因并给出这两条建议，不会和「密钥失效」混在一起。另外，公共网盘**根目录读取失败会直接报错**，不再默默当成「0 个视频」——这也是之前「有时候检测失败」却查不出原因的一个来源。

## 注意

- `/api/media.php` 返回的是带时效的凭证，站点若挂了 CDN，记得对该路径设置为不缓存；
- 直链本身即凭证，拿到的人都能看，直到过期，别往公开页面贴；
- 想长时间可用就调大 `play_ttl`，而不是去做永久公开直链。

## 自测

```bash
python tests/smoke_test.py
```

用假 astrbot 模块 + 本地模拟 `/api/media.php` 和 `/api/public.php`，覆盖指令解析、文件名匹配、缓存命中、`source`/`folder_password` 参数下发、受密码目录、上传失败降级、401、未配置、话数上限。需要 `aiohttp`。

## 结构

```

tests/smoke_test.py  离线冒烟测试

```
